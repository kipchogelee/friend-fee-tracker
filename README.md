# 朋友墊支記錄

簡單的 HTML 頁面，幫你記錄幫朋友墊支的金錢和還款。

## 功能

- 💸 記錄墊支
- 💰 記錄還款
- 📊 顯示餘額
- 📋 交易歷史
- 📤 📥 匯出/匯入資料

## 使用方式

1. 開啟 `index.html`（可以係瀏覽器直接打開，或放到任何靜態網頁空間）
2. 資料會自動存到瀏覽器的 LocalStorage
